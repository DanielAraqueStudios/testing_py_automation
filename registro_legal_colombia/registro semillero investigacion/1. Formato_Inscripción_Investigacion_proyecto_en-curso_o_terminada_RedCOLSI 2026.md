# Formato de Registro del Proyecto
## Sistema de Cotizaciones HTML Automatizado

### 1. Informacion general
- Nombre del proyecto: Sistema de Cotizaciones HTML Automatizado
- Repositorio: testing_py_automation
- Tipo: Automatizacion de cotizaciones comerciales en HTML
- Lenguaje principal: Python
- Interfaces:
  - Consola: generate_quote.py
  - GUI: quote_gui.py

### 2. Objetivo general
Implementar un flujo estandar para generar cotizaciones HTML personalizadas a partir de datos de cliente, seleccion de servicios y configuracion de precios.

### 3. Alcance funcional
- Captura de informacion del cliente y remitente.
- Seleccion de servicios disponibles:
  - Desarrollo web
  - Redes sociales
  - Bot de WhatsApp
  - Campanas de Facebook
  - Capacitacion en IA
- Carga de precios por cada servicio activo.
- Generacion de archivo cotizacion_generada.html.

### 4. Arquitectura tecnica
- Entrada: CLI y GUI.
- Logica: normalizacion de datos y armado de variables de plantilla.
- Plantilla: template.html con placeholders.
- Salida: HTML final listo para compartir.

### 5. Archivos clave
- generate_quote.py
- quote_gui.py
- run_gui.py
- template.html
- cotizacion_generada.html
- assets/

### 6. Flujo operativo
1. Ingresar datos generales.
2. Seleccionar servicios.
3. Ingresar precios solo de servicios activos.
4. Definir vigencia y condiciones de pago.
5. Generar cotizacion HTML.

### 7. Criterios de calidad
- El HTML no debe tener footer duplicado.
- Solo deben verse los servicios seleccionados.
- Los precios deben validarse como numericos.
- El enlace de contacto debe incluir company_name.

### 8. Riesgos tecnicos
- Duplicacion de bloques HTML por ediciones manuales.
- Errores de indentacion en bloques grandes embebidos en Python.

### 9. Mejoras sugeridas
- Pruebas automaticas de integridad del HTML.
- Separar bloques de servicios en parciales reutilizables.
- Estandarizar textos comerciales en un solo archivo de configuracion.
